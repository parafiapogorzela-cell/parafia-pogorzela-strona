# Parafia pw. św. Michała Archanioła w Pogorzeli

Nowa strona parafii — projekt prowadzony na koncie należącym do parafii.

## Identyfikacja wizualna (projekt, październik 2026)

Kierunek: klasyczny i elegancki. Leśna zieleń, złoto, krem, motyw skrzydeł, miecza i tarczy św. Michała Archanioła.

- `public/brand/logo-sygnet.svg` — główny znak do nagłówka.
- `public/brand/logo-pieczec.svg` — alternatywna pieczęć.
- `public/brand/logo-minimal.svg` — wersja uproszczona.

### Witryna

Kod pierwszego prototypu Next.js + Sanity (v0.2) przygotowano w oddzielnym archiwum przekazanym administratorowi parafii. **Repozytorium zawiera obecnie elementy identyfikacji wizualnej; kod aplikacji nie jest jeszcze przesłany.** Przed uruchomieniem trzeba dodać pliki projektu.

Docelowo strona ma pokazywać przede wszystkim **ogłoszenia parafialne i intencje mszalne** oraz zdjęcia kościoła i wydarzeń.

**Nie należy umieszczać w repozytorium sekretów środowiskowych ani kluczy API.**
